# CYBER ALIXEN

A cybersecurity learning and defensive security platform.

## Features

- Responsive cybersecurity dashboard
- SHA-256 text hashing
- Basic password safety estimate
- Phishing awareness quiz
- FastAPI backend
- API health check
- Security response headers

## Requirements

- Python 3.10 or newer
- pip

## Run locally

Install dependencies:

    pip install -r requirements.txt

Start the server:

    uvicorn main:app --reload

Open:

    http://127.0.0.1:8000

API documentation:

    http://127.0.0.1:8000/docs

## Important

This is a starter project, not a production-ready security service.
Do not enter real passwords or confidential information.

The community, accounts, AI assistant, and mobile apps are planned
features and are not implemented in this version.
